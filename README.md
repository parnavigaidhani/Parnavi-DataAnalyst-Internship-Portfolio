Turning Data into Decisions

Overview
This portfolio showcases my internship work on the Online Retail dataset (2009–2011).It highlights customer retention, revenue trends, KPIs, and strategic insights, supported by dashboards and hypothesis testing.

Tasks & Deliverables
Task 1 – Data Exploration  
Initial dataset cleaning, descriptive statistics, and variable overview.  

Task 2 – KPI Identification  
Defined customer retention, revenue growth, and average order value metrics.  

Task 3 – Dashboard Creation  
Built interactive Power BI dashboard visualizing retention, revenue, and geography.  

Task 4 – Insights & Hypothesis Testing  
Presentation deck with strategic insights and hypothesis testing summary.  

Task 5 – Capstone Portfolio  
This master repository consolidates all tasks and deliverables.  

Key Insights
•	Retention: Drops sharply after Month 1, stabilizing at ~25–30% by Month 3.  
•	Revenue: Grew despite fewer orders → stronger sales efficiency.  
•	AOV: Declined (~$28), showing smaller baskets.  
•	Geography: UK contributes ~70% of revenue; NL, DE, FR, IE are emerging markets.  

Recommendations
•	Boost Retention: Onboarding campaigns & personalized offers.  
•	Increase AOV: Bundles, upselling, loyalty discounts.  
•	Optimize Mix: Focus on high‑margin items.  
•	Strengthen UK Market: Loyalty programs & cross‑selling.  
•	Expand Internationally: Localized campaigns in NL, DE, FR, IE.  
•	Diversify Markets: Reduce UK dependence.
